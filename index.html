Lesson 1.3.7 · Days 1–2 · Fusion 360

Protective Case CAD Workflow

Work through these steps in order. Finish the design questions before opening Fusion 360.

Key Numbers — FDM 3D Printing

Object clearance +0.5 mm per side, object to case wall
Wall thickness 2.0 mm minimum; 2.5 mm for high-stress parts
Lid lip clearance 0.3 mm per side, lip to base opening
Lip height 3–4 mm enough to hold without being too tight
Max overhang 45° steeper angles need support material
Min feature size 1.5 mm anything smaller may not print cleanly
01

Before Fusion — Plan

Measure your object

Use the dial caliper. Measure at the widest point in each direction — include any buttons, ports, or raised features that stick out.

  • Length (longest dimension): _____ mm
  • Width: _____ mm
  • Height: _____ mm
Measure at the widest point

If your object has a bump or raised label, the case has to clear it. Measure there, not at the average.

02

Before Fusion — Plan

Decide on your case design

Answer these questions before you model anything.

  • Is the lid flat or does it follow the object's shape?
  • How does it open — straight off, or hinged?
  • Does the object need to be visible through the lid?
  • Will you add any branding, grip texture, or access holes?

Sketch both parts on paper — the base (cup that holds the object) and the lid. Label which features go on which part.

03

Before Fusion — Calculate

Calculate your case dimensions

This step prevents the most common failure — printing a case that doesn't fit. Do the math now, before you sketch anything.

Base — outer dimensions (what you'll sketch)
Outer W = Object_W + 5.0 mm  (1 mm clearance + 2 mm walls × 2)
Outer L = Object_L + 5.0 mm
Extrude H = Object_H + 2.5 mm  (0.5 mm clearance + 2 mm floor)
Lid lip — outer dimensions (fits inside the base opening)
Lip W = Object_W + 0.4 mm  (inner cavity − 0.6 mm fit clearance)
Lip L = Object_L + 0.4 mm
Lip H = 3.0 mm
Why Shell gives you 2× wall thickness

When you Shell with 2 mm, Fusion adds 2 mm of wall on every side. Outer W − (2 mm + 2 mm) = Inner W. So if your outer sketch is Object_W + 5 mm, the inner cavity is exactly Object_W + 1 mm — half a millimeter clearance on each side. ✓

04

In Fusion 360 — Setup

Set up your file

  • File → New Design
  • Browser: right-click Components → New Component → name it "Base"
  • Add a second component → name it "Lid"
  • Right-click Base → Activate (the radio button next to it turns blue)
  • Inspect → Change Active Units → Millimeters
Always check which component is active

If the wrong component is active, your geometry goes into the wrong part. Before every sketch, glance at the browser to confirm.

05

In Fusion 360 — Base

Model the base

  • Create Sketch on the Top plane
  • Use Center Rectangle — sketch from the origin for symmetry
  • Sketch the outer profile: Outer W × Outer L from Step 3
  • Add dimensional constraints — confirm the sketch turns fully black (no blue lines)
  • Finish Sketch → Extrude upward by your Extrude H from Step 3
  • Modify → Shell → select the top face → set wall thickness to 2.0 mm
After Shell

You should have a box open at the top with uniform 2 mm walls and a 2 mm floor. The interior cavity dimensions should be Object_W + 1 mm and Object_L + 1 mm. Verify this with Inspect → Measure.

06

In Fusion 360 — Lid

Model the lid

  • Browser: right-click Lid → Activate
  • Create Sketch on the Top plane (same plane as the base)
  • Sketch the outer profile: same Outer W × Outer L as the base
  • Finish Sketch → Extrude upward by 2 mm (lid thickness)
  • Create a new sketch on the bottom face of the lid
  • Sketch the lip: Lip W × Lip L from Step 3 — centered
  • Finish Sketch → Extrude downward by 3 mm
Tip: Use Offset for the lip sketch

In the lip sketch, use Sketch → Offset to shrink the outer profile by the exact clearance amount instead of re-entering dimensions. Offset inward by 0.3 mm.

07

In Fusion 360 — Verify

Check the fit

  • Make sure both Base and Lid are visible (eye icon in browser)
  • Position the lid above the base — in the browser, right-click Lid → Move/Copy
  • Move it down so the lip sits inside the base opening — do they visually align?
  • Use Inspect → Measure to confirm the clearance gap between the lip and the base wall is ~0.3 mm
Clearance looks like interference in the view

A 0.3 mm gap is too small to see clearly — use Inspect → Measure, not the eyeball test. If your gap is 0 or negative, the parts won't fit.

08

Before Printing — Final Check

Printability check

Answer each question before sending to the printer.

  • Walls ≥ 2 mm? Check your thinnest section. Thinner walls may snap.
  • No overhangs > 45°? Steep overhangs print poorly without support. Redesign or add a chamfer.
  • Flat bottom face? The print must have a face that lies flat on the print bed.
  • No floating geometry? Every feature must connect to the main body.
  • File saved and named? Lastname_CasePart.f3d format.
All checks pass?

Export each component as a separate STL (right-click component in browser → Save As Mesh) and share with your teacher for print review.
